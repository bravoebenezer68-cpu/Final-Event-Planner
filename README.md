# Eventify – Event Planner Web Application

## Project Description
Eventify is a web-based Event Planner application designed to help users organize and manage events easily. It allows users to create events, manage guests, track event statuses, and customize their organizer settings.

## Features
- Dashboard with event statistics
- Create, view, edit, and delete events
- Event categories: Birthday, Wedding, Conference, Seminar, Meeting, and Other
- Event statuses: Upcoming, Ongoing, Completed, and Cancelled
- Guest management
- Search events and guests
- Organizer profile settings
- Dark Mode
- Responsive design for desktop and mobile devices
- Local Storage for saving data in the browser

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage

## How to Run the Project
1. Download or copy the EventPlanner project folder.
2. Open the folder in Visual Studio Code.
3. Install the Live Server extension if it is not installed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. The Eventify application will open in your browser.

## Project Files
- `index.html` – Contains the structure of the application.
- `style.css` – Contains the design and styling.
- `script.js` – Contains the application functionality.
- `README.md` – Contains project documentation.

## Data Storage
Eventify uses browser Local Storage to save event and guest information. Data is stored in the browser used to access the application.
